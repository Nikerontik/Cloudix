# Cloudix

Локальный P2P-мессенджер без сервера. Cloudix работает поверх вашей локальной сети (Wi-Fi/LAN), автоматически находит других пользователей приложения и позволяет обмениваться сообщениями, медиа и совершать звонки без каких-либо централизованных серверов.

> ⚠️ Это первая версия приложения. Возможны баги — будем благодарны за обратную связь.

## Возможности

- 🔍 Автоматическое обнаружение собеседников в локальной сети (без ручного ввода IP)
- 💬 Обмен текстовыми сообщениями, фото и видео
- ✅ Статусы прочтения, индикатор "печатает…"
- 😀 Реакции на сообщения
- 📌 Локальный раздел "Избранное" (хранится только на устройстве)
- 📞 Аудио- и видеозвонки на базе WebRTC, с регулировкой громкости собеседника
- 📶 Отображение задержки соединения (ping) в реальном времени
- 🚫 Блокировка пользователей
- 🌗 Светлая и тёмная темы, переключение языка интерфейса
- 🔒 Все данные хранятся локально в SQLite, ничего не уходит на сторонние серверы

## Технологии

- **Backend:** Go, [Wails v2](https://wails.io), SQLite (`modernc.org/sqlite`)
- **Frontend:** React, Framer Motion
- **Связь:** TCP-транспорт для сообщений, UDP multicast + unicast для обнаружения пиров, WebRTC для звонков

## Модель безопасности

Cloudix рассчитан на **доверенную сеть** (домашний LAN или частный VPN вроде
RadminVPN/Hamachi). Медиапоток звонков шифруется (WebRTC/DTLS), но текстовые
сообщения и сигналинг звонков передаются в открытом виде и **не подписываются** —
любой участник той же сети технически может отправить сообщение от чужого имени.
Не используйте Cloudix в недоверенных / публичных сетях.

## Требования для сборки

- [Go](https://go.dev/dl/) 1.25+
- [Node.js](https://nodejs.org/) 18+
- [Wails CLI v2](https://wails.io/docs/gettingstarted/installation)

Установка Wails CLI:

```bash
go install github.com/wailsapp/wails/v2/cmd/wails@latest
```

## Разработка

```bash
wails dev
```

Приложение запустится в режиме разработки с горячей перезагрузкой фронтенда.

## Сборка релиза

### macOS

```bash
wails build -platform darwin/universal
```

Готовое приложение появится в `build/bin/Cloudix.app`.

### Windows

```bash
wails build -platform windows/amd64
```

Готовый `.exe` появится в `build/bin/Cloudix.exe`.

> Кросс-компиляция между macOS и Windows в Wails ограничена — для сборки `.exe` рекомендуется собирать непосредственно на Windows или в CI. В репозитории есть workflow `.github/workflows/build.yml` с матрицей `windows-latest` / `macos-latest`.

## Структура проекта
```
Cloudix/
├── backend/
│   ├── app/        # Bound-методы, доступные фронтенду, роутер входящих пакетов
│   ├── models/     # Общие структуры данных, типы wire-протокола
│   ├── storage/    # Работа с SQLite
│   ├── transport/  # TCP-транспорт для P2P-обмена
│   └── discovery/  # UDP multicast + unicast обнаружение пиров
├── frontend/
│   ├── src/
│   │   ├── App.jsx # Основной UI
│   │   └── i18n.js # Локализация (ru/en)
│   └── wailsjs/    # Автогенерируемые биндинги Wails
└── wails.json
```
